# NEURAFLOK 0.1.1

This release adds ready-to-install desktop packages and improves project-chat reliability and answer presentation.

## Highlights

- Installers for Windows x64 and ARM64, macOS Intel and Apple silicon, and Linux x64 and ARM64.
- SHA-256 checksums for the release files.
- Improved project-chat context recovery and file attachment handling.
- Clearer Markdown rendering for structured answers, code, and tables.
- More consistent plan-mode feedback and project loading behavior.

## Installation

Download the package for your operating system and processor from the assets below. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
