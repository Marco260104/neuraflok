# NEURAFLOK 0.1.4

This release provides the complete NEURAFLOK installer set after correcting two cross-platform packaging blockers.

## Highlights

- Windows installers for x64 and ARM64.
- macOS DMG and ZIP packages for Intel and Apple silicon.
- Linux AppImage and DEB packages for x64 and ARM64.
- A packaged provider extension and native source archive.
- SHA-256 checksums for every release asset.
- CircleCI builds, smoke-tests, and verifies the complete release before publication.

## Fixes

- Added non-personal maintainer metadata required by Linux DEB packaging.
- Exposed the shared macOS UI snapshot type to the helper files that store and read snapshots.

## Installation

Download the package for your operating system and processor from the release assets. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
