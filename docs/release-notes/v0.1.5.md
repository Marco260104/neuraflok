# NEURAFLOK 0.1.5

This release corrects the CircleCI installer checks so a release can publish only after each platform package has been inspected and smoke-tested successfully.

## Fixes

- Kept macOS bundle version metadata equal to the public semantic version instead of appending CircleCI's internal build number.
- Made Linux package and GUI smoke-test failures report the failing check and captured application output.

## Installation

Download the package for your operating system and processor from the release assets. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
