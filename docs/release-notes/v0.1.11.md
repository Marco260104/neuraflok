# NEURAFLOK 0.1.11

This release fixes the integrated browser toolbar path in packaged desktop builds and verifies the macOS Intel app launch under Rosetta.

## Fixes

- Packaged builds now load the integrated browser toolbar from the nested Vite output directory, matching the path used by the development server.
- The release pipeline continues to inspect the macOS Intel DMG, ZIP, bundle metadata, executable permissions, and architecture, and now checks that the app reaches its ready state under Rosetta.

## Installation

Download the package for your operating system and processor from the release assets. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
