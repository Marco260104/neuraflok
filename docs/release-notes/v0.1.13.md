# NEURAFLOK 0.1.13

## Fixed

- A macOS Keychain request that does not answer now times out instead of holding the app's initial state indefinitely. Further checks back off briefly while the login Keychain is unlocked or its prompt is resolved.
- Add a focused regression test for a Keychain request that never resolves.

## Release verification

- Uses the existing debug-only startup phase markers (`NEURAFLOK_DEBUG=1`) when diagnosing packaged macOS launch failures.
