# NEURAFLOK 0.1.16

## Improvements

- Keeps long-running chat work visibly active while provider snapshots or intermediate replies are delayed.
- Queues messages sent during active work so they run after the current turn and do not replace its Stop action.
- Automatically resumes verified idle DeepSeek turns and offers a simple Continue action only after safe recovery attempts are exhausted.
- Resets DeepSeek idle detection after using its Continue control so the resumed answer has time to render.
- Improves the Windows app icon and makes the top-bar social buttons easier to click.

## Verification

- DeepSeek execution and browser-chat recovery tests passed.
- Focused chat timeline and queue tests passed.
- Production build, typecheck, privacy checks, and third-party notice validation passed.
