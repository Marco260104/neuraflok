# NEURAFLOK 0.1.7

This release fixes the Linux package smoke test to locate the desktop entry generated by the configured application identity.

## Fixes

- Checked the actual `com.neuraflok.desktop` launcher entry installed by the DEB package.

## Installation

Download the package for your operating system and processor from the release assets. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
