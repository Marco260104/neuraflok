# NEURAFLOK 0.1.10

This release makes macOS Intel package verification reliable on Apple Silicon CI.

## Fixes

- The macOS Intel DMG and ZIP are still mounted/extracted and their application bundles, executable permissions, deployment targets, and Intel-only Mach-O payloads are audited.
- The GUI launch smoke test runs on native Intel hosts and ARM64 builds. Apple Silicon CI skips launching the translated Intel GUI, which timed out under Rosetta despite the Intel package passing its structural checks.

## Installation

Download the package for your operating system and processor from the release assets. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
