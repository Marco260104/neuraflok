# NEURAFLOK 0.1.2

This is the first public release of NEURAFLOK desktop installers.

## Highlights

- Windows installers for x64 and ARM64.
- macOS DMG and ZIP packages for Intel and Apple silicon.
- Linux AppImage and DEB packages for x64 and ARM64.
- A packaged provider extension and native source archive.
- SHA-256 checksums for every release asset.
- CircleCI builds, smoke-tests, and verifies the complete release before publication.

## Installation

Download the package for your operating system and processor from the assets below. On Windows, run the `NEURAFLOK-Setup` installer. On macOS, open the DMG or ZIP package. On Linux, use the AppImage or DEB package.

Some macOS packages may be unsigned and unnotarized. Review the installation guidance in [SECURITY.md](https://github.com/Marco260104/neuraflok/blob/main/SECURITY.md) before opening them.
