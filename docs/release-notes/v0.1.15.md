# NEURAFLOK 0.1.15

## Improvements

- Enlarges the branded app and extension icons at taskbar, launcher, and small tile sizes.
- Connects the top-bar GitHub and Telegram buttons to the NEURAFLOK repository and community.
- Explains the supported API routes for OpenAI, Claude through OpenRouter, DeepSeek, and OpenAI-compatible endpoints.
- Adds configurable custom API connections using OpenAI Chat Completions or Anthropic Messages, with endpoint paths, authentication headers, and encrypted extra headers.
- Adds direct Anthropic Messages chat and Goal/Plan decisions, including model-list pagination.
- Clarifies that the local browser-session/MCP workflow is intended for small project tasks, with corporate projects using organization-approved APIs or gateways.
- Updates the English terms and privacy policy both in the repository and in the app.

## Windows installer

Windows installers are unsigned in this release while trusted code signing is deferred. Windows Defender SmartScreen may show an unknown-publisher warning.
